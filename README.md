**📚 Library Management App (iOS)**

An iOS library management application built with SwiftUI and Supabase.
This app allows users to browse book catalogs and enables admins to manage book loans and returns.

✨ Key Features
- Browse book catalog with cover, status, and details
- Admin login with secure password validation
- Manage book loans and returns
- Automatic book status updates using database triggers

🛠 Tech Stack
- Frontend: SwiftUI (MVVM)
- Backend: Supabase (PostgreSQL)
- Architecture: MVVM + OOP
- Methodology: Agile
  
🧠 OOP Implementation
- Inheritance: Shared base ViewModel
- Polymorphism: Overridden load() methods
- Overloading: Multiple method signatures for loan actions
